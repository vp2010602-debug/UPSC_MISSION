HOW TO UPDATE GITHUB
1. Extract Mission-UPSC-v28.9-GitHub-Update.zip.
2. Upload all files and the assets folder to the ROOT of the existing GitHub repository.
3. Choose Replace/Overwrite for files with the same names.
4. Do not delete or replace your existing firebase-config.js.
5. Wait for GitHub Pages deployment to finish.
6. Reload the website. If the old version remains, open App & Offline and use Check App Update, or clear the site cache once.
