# Mission UPSC AI OS V30.0.6 — Temporal UI Fix

This release preserves the V30.0 design and makes two narrowly scoped corrections:

1. Every date, time, date-time, month and week field is placed inside a real clipping shell so iPad/iPhone Safari cannot paint the native control outside its card.
2. The extra `Show Sections / Hide Sections` button is removed. The hamburger in the navy top section bar is the single section-menu control on tablet and phone.

No study data, Firebase configuration, AI module, calendar record, note, test or revision workflow is changed.
