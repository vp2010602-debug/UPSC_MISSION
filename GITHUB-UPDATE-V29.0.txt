UPLOAD METHOD
1. Extract this ZIP.
2. Open your existing Mission UPSC GitHub repository.
3. Upload every file and folder INSIDE this extracted folder to the repository root.
4. Select Replace/Overwrite for files with the same names.
5. Commit the changes and wait 2–5 minutes for GitHub Pages to deploy.
6. Hard refresh the website:
   Windows: Ctrl + Shift + R
   iPad/iPhone Safari: close the tab and reopen it.
7. If the Home Screen app still shows the old version, delete that shortcut and add the website again using Safari → Share → Add to Home Screen.
