# Mission UPSC AI OS V30.0.7

## Centered Temporal Values + Top-Bar Hamburger Fix

This update keeps the V30.0 visual design intact and makes two focused corrections:

1. Every date, time, date-time, month and week field now uses a centred display label inside the existing input box while retaining the native browser picker.
2. The section sidebar is opened and closed only from the hamburger in the navy top bar. On large tablets and laptops the navy bar begins after the visible sidebar, so the hamburger is never hidden underneath it. When the sidebar is collapsed the workspace expands to full width.

No study data, Firebase configuration, Jarvis modules, calendar records or existing workflows are changed.
