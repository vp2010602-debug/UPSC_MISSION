# Mission UPSC AI OS V30.0.1 — Responsive Tablet & Phone Fix

This is a non-destructive responsive update built from the selected V30.0 Smart Calendar base.

## Fixed

- iPad/tablet now uses the mobile app shell instead of the cramped desktop sidebar.
- Sidebar opens as a drawer with an overlay on screens up to 1180px.
- Added safe bottom spacing so the fixed Home/Jarvis/Today/Recall/Sections dock no longer covers controls.
- Removed horizontal overflow and right-side card clipping.
- AI Daily Command planner and Morning Intelligence Brief stack cleanly on tablet.
- Smart Recall cards stack; checkbox alignment and upload controls are corrected.
- Current Affairs input and output actions stack and remain fully visible.
- Saarathi command controls wrap correctly; response panel moves below on tablet.
- Smart Calendar retains its two mini sections on wide tablets and stacks in portrait.
- App & Offline Centre cards and controls remain visible above the dock.
- Phone-specific one-column controls, safe-area spacing and narrow-dock sizing added.

## Preserved

All V30.0 features, local storage keys, Firebase configuration, notes, calendar data, Jarvis, Saarathi, revision data, tests and files are unchanged.
