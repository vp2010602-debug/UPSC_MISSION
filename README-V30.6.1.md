# Mission UPSC AI OS V30.6.1 — Simple Daily CA + Simplified Mentorship

## Daily Current Affairs
- One primary **Get Today’s UPSC Headlines** button.
- Headline collection uses zero Gemini tokens.
- JARVIS auto-selects the most relevant topics.
- One manual **Generate Selected UPSC Notes with Gemini** button.
- Source selection and digest import remain available under optional details.
- Existing Tracker archive, notes, Prelims, Mains, revision and print integrations are preserved.

## Saarthi Mentorship
- Main navigation reduced to Home, Add Plan, This Week, Tests, Notes and Progress.
- Daily check-in, sessions/doubts and microtopic tools moved under More.
- Weekly plan workflow reduced to Read Upload → AI Make Weekly Plan → Approve & Add Everywhere.
- Manual target and test forms are collapsed by default.
- Existing data, calendar, revision, test and report integrations are preserved.

## Deployment
Upload the GitHub update files to the repository root and hard-refresh. No Firebase redeployment is required if the V30.6 source-fetch function is already deployed.
