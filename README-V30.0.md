# Mission UPSC AI OS V30.0 — Smart Calendar Composer

## Main upgrade
- Rebuilt AI Smart Calendar composer as one parent workspace with two clear mini-sections.
- **Quick Calendar** handles one manual event.
- **AI Time-Block Planner** creates a full schedule.
- Both sections save into the same integrated month calendar.
- Fixed field, button, spacing, height and responsive alignment issues.
- Added visible field labels, duration unit, clearer prompts and AI-plan preview label.
- Added mobile/tablet stacking and dark-mode styling.
- Preserved all V29.2 functions, IDs, local storage, Firebase data and AI actions.

## Deployment
Upload the V30.0 GitHub Update files to the repository root and replace matching files. Do not delete `firebase-config.js` or existing data. After deployment, hard refresh once.
